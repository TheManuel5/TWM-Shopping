# Entrega TWM local

Consultar README principal para instalar y ejecutar. La app utiliza los cuatro SQL mejorados con soporte web transaccional, una base limpia de entrega y una copia separada para pruebas.

Referencia visual: 34 páginas de Tarea Grupa N°02.pdf. Pantallas y evidencia de navegador en test-results. Validaciones, navegación, CRUD, bcrypt, Skeleton y eventos de consola sin contraseñas implementados. La configuración Raspberry queda para después de la revisión local.

La evaluación definitiva del profesor también incluye minutas y participación del equipo: deben entregarse con evidencia real. No se afirma que los nombres generados en los TXT sean personas verificadas ni que los comprobantes internos sean documentos tributarios.
